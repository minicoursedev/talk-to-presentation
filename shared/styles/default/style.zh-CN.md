# 预设风格参考

这套参考提供「说说变简报」的起始视觉语言。可在新案件中沿用或替换，不代表所有案件都已确认使用它。

开启同目录 [reference.html](reference.html)，比较标题、叙述、关系与提问四种构图。它是可观看的风格参考，使用中性几何图形示范，不是案件插图，也不是可直接套用任意内容的四页成品。

## 核心样板：说书人（storyteller 1.0.0）

整份简报是一段连贯的叙事，我们扮演说书人，带观众从原本的理解走到新的理解。这是专案预设提供、可由使用者修改或替换的样板，并非 skill 写死的唯一表达方式。

- **叙事方式**：先找出观众的起点、核心问题与最后要带走的理解，再安排铺陈、发展、转折及收束。依内容选择顺序与篇幅，不要求每份简报套固定章节数，也不为戏剧效果编造事实。
- **说话口吻**：像对观众说话，以具体情境带出概念。旁白承接画面并推进理解，不逐字重复每页标题。
- **逐页推进**：每页记录叙事作用、承接上一页的线索及带往下一页的方向；文字、图片、旁白与动画共同完成这个作用。翻页后仍能感受到是同一个故事。
- **视觉语言**：依下方共同视觉依据与参考页建立连贯性，图片的主体及关系依各页语意形成。
- **呈现节奏**：重点留有理解时间，提问、转折与收束有适当停顿；具体语速、转场及长度依使用情境决定，不设固定加速倍数。
- **整体验收**：连续观看时能理解为何从这一页走到下一页、每页如何推进核心讯息，以及结尾是否回应开场。逐页素材完整与技术检查只是其中一部分。

## 修改、替换与保存版本

先复制本目录到用户数据根目录的 `shared/styles/default/`，再编辑副本的 `style.md` 三语文件、`reference.html` 及其他参考资产，并更新 `style.json` 的 `version`。这份样板同时承载叙事、口吻、视觉与节奏，并不限于色彩或排版。

若要保留多套风格，复制本目录到用户数据根目录的 `shared/styles/<名称>/`，调整内容与 `style.json` 的 `id`／`version`，用下列命令选用；省略 `--style` 时使用 `default`：

```bash
python3 "$PROJECT_ROOT/tools/init_case.py" my-talk --style default
```

新案件会把整套样板复制到 `content/style/`，并在 `case.json.style` 保存识别字、版本、来源与快照位置。制作时以案件快照为准，因此更新共用样板不会改动既有案件。自订参考资产应放在样板目录内，以相对路径连结；外部连结内容不属于快照。

既有案件未记录样板时，保留目前成果与选择，不自动套用预设。只有使用者要求迁移时才保留旧快照、建立新快照并更新案件记录，逐项确认受影响的文稿、图片、旁白与版面。没有自动更新既有案件的命令。

## 共同视觉依据

- 目前基准画幅为直式 1080 × 1920；案件可另行指定。
- 深蓝底、明亮主文字、灰白次文字、青色强调。讯息层级由大小、位置与色彩共同表达；浅色页需重新核对对比。
- 系统无衬线字体，主讯息粗体。完整保留有意义的次标与说话者标示。
- 一页一个主要视觉焦点。图片与文字共用构图，保留明确文字空间；插图不烘焙标题或字幕。
- 预设参考以简洁几何、圆角形体、少量色彩及清楚的物件关系示范。若改用其他插画语言，先保存代表性参考并在同案中一致使用。
- 连贯来自稳定的色彩、字体、线条／材质与构图逻辑；不同页可用不同场景及版型。图片是否逐页提供，由本次制作需求决定。

## 如何用于制作

在案件 `draft.md` 记录选用的参考路径、保留特征、使用者指定的变更，以及已接受的代表页。每次制图同时使用风格参考与该页的内容规划；接续页面也查看同案已接受的图片。需要新风格时，保存其文字规格及实际参考资产，让后续任务可以重用。

目前这是代理制图与排版的共同参考；HTML 工具仍使用既有内建样式，尚未提供读取风格设定后自动换肤的功能。若选定风格超出现有版型，须明确调整排版来源并预览验证，不能只改风格名称就宣称已套用。语速、声线、字幕与转场另外记在案件制作设定。

## 连贯叙事示例

中性示例：「想说的太多」带出准备内容的困境 →「观众只记住零散片段」呈现影响 →「先选一个核心问题」形成转折 →「让观众带走清楚的理解」回应开场。这是同一个故事的推进示范，不是固定四页公式。

每页同时规划画面重点、旁白要补充的理解、图片中的关系及前后承接；它们共同推进故事，不必重复说同一句话。
