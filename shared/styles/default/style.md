# 預設風格參考

這套參考提供「說說變簡報」的起始視覺語言。可在新案件中沿用或替換，不代表所有案件都已確認使用它。

開啟同目錄 [reference.html](reference.html)，比較標題、敘述、關係與提問四種構圖。它是可觀看的風格參考，使用中性幾何圖形示範，不是案件插圖，也不是可直接套用任意內容的四頁成品。

## 核心樣板：說書人（storyteller 1.0.0）

整份簡報是一段連貫的敘事，我們扮演說書人，帶觀眾從原本的理解走到新的理解。這是專案預設提供、可由使用者修改或替換的樣板，並非 skill 寫死的唯一表達方式。

- **敘事方式**：先找出觀眾的起點、核心問題與最後要帶走的理解，再安排鋪陳、發展、轉折及收束。依內容選擇順序與篇幅，不要求每份簡報套固定章節數，也不為戲劇效果編造事實。
- **說話口吻**：像對觀眾說話，以具體情境帶出概念。旁白承接畫面並推進理解，不逐字重複每頁標題。
- **逐頁推進**：每頁記錄敘事作用、承接上一頁的線索及帶往下一頁的方向；文字、圖片、旁白與動畫共同完成這個作用。翻頁後仍能感受到是同一個故事。
- **視覺語言**：依下方共同視覺依據與參考頁建立連貫性，圖片的主體及關係依各頁語意形成。
- **呈現節奏**：重點留有理解時間，提問、轉折與收束有適當停頓；具體語速、轉場及長度依使用情境決定，不設固定加速倍數。
- **整體驗收**：連續觀看時能理解為何從這一頁走到下一頁、每頁如何推進核心訊息，以及結尾是否回應開場。逐頁素材完整與技術檢查只是其中一部分。

## 修改、替換與保存版本

先複製本目錄到使用者資料根目錄的 `shared/styles/default/`，再編輯副本的 `style.md` 三語文件、`reference.html` 及其他參考資產，並更新 `style.json` 的 `version`。這份樣板同時承載敘事、口吻、視覺與節奏，並不限於色彩或排版。

若要保留多套風格，複製本目錄到使用者資料根目錄的 `shared/styles/<名稱>/`，調整內容與 `style.json` 的 `id`／`version`，用下列命令選用；省略 `--style` 時使用 `default`：

```bash
python3 "$PROJECT_ROOT/tools/init_case.py" my-talk --style default
```

新案件會把整套樣板複製到 `content/style/`，並在 `case.json.style` 保存識別字、版本、來源與快照位置。製作時以案件快照為準，因此更新共用樣板不會改動既有案件。自訂參考資產應放在樣板目錄內，以相對路徑連結；外部連結內容不屬於快照。

既有案件未記錄樣板時，保留目前成果與選擇，不自動套用預設。只有使用者要求遷移時才保留舊快照、建立新快照並更新案件記錄，逐項確認受影響的文稿、圖片、旁白與版面。沒有自動更新既有案件的命令。

## 共同視覺依據

- 目前基準畫幅為直式 1080 × 1920；案件可另行指定。
- 深藍底、明亮主文字、灰白次文字、青色強調。訊息層級由大小、位置與色彩共同表達；淺色頁需重新核對對比。
- 系統無襯線字體，主訊息粗體。完整保留有意義的次標與說話者標示。
- 一頁一個主要視覺焦點。圖片與文字共用構圖，保留明確文字空間；插圖不烘焙標題或字幕。
- 預設參考以簡潔幾何、圓角形體、少量色彩及清楚的物件關係示範。若改用其他插畫語言，先保存代表性參考並在同案中一致使用。
- 連貫來自穩定的色彩、字體、線條／材質與構圖邏輯；不同頁可用不同場景及版型。圖片是否逐頁提供，由本次製作需求決定。

## 如何用於製作

在案件 `draft.md` 記錄選用的參考路徑、保留特徵、使用者指定的變更，以及已接受的代表頁。每次製圖同時使用風格參考與該頁的內容規劃；接續頁面也查看同案已接受的圖片。需要新風格時，保存其文字規格及實際參考資產，讓後續任務可以重用。

目前這是代理製圖與排版的共同參考；HTML 工具仍使用既有內建樣式，尚未提供讀取風格設定後自動換膚的功能。若選定風格超出現有版型，須明確調整排版來源並預覽驗證，不能只改風格名稱就宣稱已套用。語速、聲線、字幕與轉場另外記在案件製作設定。

## 連貫敘事示例

中性示例：「想說的太多」帶出準備內容的困境 →「觀眾只記住零散片段」呈現影響 →「先選一個核心問題」形成轉折 →「讓觀眾帶走清楚的理解」回應開場。這是同一個故事的推進示範，不是固定四頁公式。

每頁同時規劃畫面重點、旁白要補充的理解、圖片中的關係及前後承接；它們共同推進故事，不必重複說同一句話。
