# YouTube 影片上傳

本 skill 處理已完成影片的 YouTube Studio 交付。需要重製畫面、配音或 MP4 時，使用 [簡報製作 skill](../presentation-production/SKILL.md)。使用者案件與帳號決策留在案件或當次任務，不寫入共用 skill。

## 上傳前

- 確認使用者已授權這支影片的上傳或修改，並讀取當次指定的頻道、標題、說明、播放清單、字幕語言與瀏覽權限。沿用對話中已確定的選擇；只釐清會改變發布結果的缺項。不要把前一支影片的私人或公開設定當成預設。
- 從案件找出實際 MP4、SRT、可選封面及內容來源，確認檔案存在、影片長度符合要求。未完成的視覺、聽感或事實查核不得寫成已驗收。使用者只要求修改既有影片時，編輯原影片 ID，避免重複上傳。
- 在 Studio 核對目前頻道與目標播放清單。名稱相近但不同時，依使用者指定名稱選擇；無法判定時詢問，不自行建立可能重複的清單。

## Studio 流程

1. 上傳 MP4，確認表單顯示正確檔名與產生的影片連結。填入當次標題、說明及可驗證來源；設定使用者選定的播放清單、觀眾與其他適用欄位。付費宣傳、合成內容等揭露依實際素材判斷，不套固定答案。封面僅在有合適素材且任務需要時上傳。
2. 需要可切換字幕時，逐語言上傳含時間碼的 SRT，等字幕文字與時間碼載入後按「完成」或「發布」。MP4 內嵌字幕不代表 YouTube 已建立字幕軌。繁轉簡只轉字幕文字，保留段序與時間碼，先檢查段數和時間碼完全一致；新增的 SRT 放在案件資料目錄。
3. 網頁選檔時，先啟動瀏覽器的 file chooser 等待，再點畫面可見的「選取檔案／上傳檔案」並以絕對路徑設定檔案。若工具支援 `waitForEvent('filechooser')` 與 `chooser.setFiles(...)`，直接完成選檔，不要求使用者代選。
4. 查看平台初步檢查，依已授權的瀏覽權限明確選擇「公開」「不公開」「私人」或排程，再完成儲存／發布。不要以暫存為私人或上傳進度訊息推定最終權限。

## 完成條件

- 在 Studio 影片清單或編輯頁確認標題、影片 ID、時長與最終瀏覽權限；在播放清單的影片頁確認該影片確實列入。
- 在字幕語言頁確認每個要求的字幕軌顯示已發布；僅開啟編輯器或選取檔案不算完成。若要求觀眾端字幕呈現或定位，再到播放器核對；普通 SRT 不保證固定畫面位置。
- 回報影片與播放清單連結、實際權限、已發布的字幕語言，以及尚未做的人工觀看／聆聽驗收。只記錄已觀察到的狀態。
