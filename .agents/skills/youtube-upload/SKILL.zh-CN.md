# YouTube 视频上传

本 skill 处理已完成视频的 YouTube Studio 交付。需要重制画面、配音或 MP4 时，使用[演示文稿制作 skill](../presentation-production/SKILL.zh-CN.md)。用户案例与账号决策留在案例或当次任务，不写入共用 skill。

## 上传前

- 确认用户已授权这支视频的上传或修改，并读取当次指定的频道、标题、说明、播放列表、字幕语言与可见性。沿用对话中已确定的选择；只澄清会改变发布结果的缺项。不要把上一支视频的私人或公开设置当成默认值。
- 从案例找到实际 MP4、SRT、可选封面及内容来源，确认文件存在、视频长度符合要求。未完成的视觉、听感或事实核查不得写成已验收。用户只要求修改现有视频时，编辑原视频 ID，避免重复上传。
- 在 Studio 核对当前频道与目标播放列表。名称相近但不同时，按用户指定名称选择；无法判断时询问，不自行创建可能重复的列表。

## Studio 流程

1. 上传 MP4，确认表单显示正确文件名与生成的视频链接。填写当次标题、说明及可核查来源；设置用户选定的播放列表、受众与其他适用字段。付费推广、合成内容等披露根据实际素材判断，不套固定答案。仅在有合适素材且任务需要时上传封面。
2. 需要可切换字幕时，逐语言上传含时间码的 SRT，等待字幕文字与时间码载入后点击“完成”或“发布”。MP4 内嵌字幕不代表 YouTube 已创建字幕轨。繁转简只转换字幕文字，保留序号与时间码，先检查段数和时间码完全一致；新增的 SRT 放在案例数据目录。
3. 网页选文件时，先启动浏览器的 file chooser 等待，再点击画面可见的“选择文件／上传文件”并以绝对路径设置文件。如果工具支持 `waitForEvent('filechooser')` 和 `chooser.setFiles(...)`，直接完成选文件，不要求用户代选。
4. 查看平台初步检查，按已授权的可见性明确选择“公开”“不公开”“私人”或排程，再完成保存／发布。不要根据暂存为私人或上传进度消息推断最终可见性。

## 完成条件

- 在 Studio 视频列表或编辑页确认标题、视频 ID、时长与最终可见性；在播放列表的视频页确认该视频确实列入。
- 在字幕语言页确认每个要求的字幕轨显示已发布；仅打开编辑器或选择文件不算完成。如果要求观众端字幕显示或定位，再到播放器核对；普通 SRT 不保证固定画面位置。
- 回报视频与播放列表链接、实际可见性、已发布的字幕语言，以及尚未进行的人工观看／聆听验收。只记录已观察到的状态。
