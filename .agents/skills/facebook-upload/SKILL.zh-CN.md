# 台南AI爽 Facebook 视频上传

本 skill 处理已完成视频的 Facebook 交付。视频制作使用[演示文稿制作 skill](../presentation-production/SKILL.zh-CN.md)。目标粉丝专页是[台南AI爽](https://www.facebook.com/profile.php?id=61594422884007)；其他粉丝专页须由用户另行指定。

## 上传前

- 确认当次上传或修改已有用户授权，找到案例中的实际 MP4 与当次标题、说明及可选字幕或封面。沿用对话中已确定的选择。
- **先切换为“台南AI爽”粉丝专页身份**，再打开上传界面。核对页面名称与网址中的 ID `61594422884007`，并确认目前是以该粉丝专页管理者身份操作。若无法切换或核对，停止发布并报告具体阻碍；不可用个人账号或其他粉丝专页代发。
- 在页面或内容库确认同一视频是否已发布；若用户要求更新现有帖子，优先编辑原帖，避免重复发布。

## 发布

1. 根据视频和用户要求选择 Reel 或普通视频帖子。通过选文件界面上传实际 MP4；若浏览器工具支持 file chooser，先等待 `filechooser`，点击上传控件，再用 `chooser.setFiles(...)` 指定绝对路径，不要求用户代选。
2. 填写当次确认的文案，检查预览、受众、排程及平台要求的标记。不要沿用上一视频的文案或可见性；AI 内容标记根据实际素材与平台要求判断。
3. 等待平台完成上传与初步检查，再按当次授权发布。发布中的提示不是完成证据；若平台仍在处理，继续核查。

## 完成条件

- 在台南AI爽粉丝专页找到新 Reel 或帖子，打开专属链接，核对页面身份、文案及实际分享对象。若平台仍在处理，明确报告处理状态，不声称已经可以观看。
- 报告已核对的 Facebook 链接与可见性；只记录实际观察到的字幕、封面及播放状态。
