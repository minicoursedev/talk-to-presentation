# 台南AI爽 Facebook 影片上傳

本 skill 處理已完成影片的 Facebook 交付。影片製作使用 [簡報製作 skill](../presentation-production/SKILL.md)。目標粉絲專頁是 [台南AI爽](https://www.facebook.com/profile.php?id=61594422884007)；其他粉絲專頁須由使用者另行指定。

## 上傳前

- 確認當次上傳或修改已有使用者授權，找出案件中的實際 MP4 與當次標題、說明及可選字幕或封面。沿用對話中已確定的選擇。
- **先切換為「台南AI爽」粉絲專頁身分**，再開啟上傳介面。核對頁面名稱與網址中的 ID `61594422884007`，並確認目前是以該粉絲專頁管理者身分操作。若無法切換或核對，停止發布並回報具體阻礙；不可用個人帳號或其他粉絲專頁代發。
- 在頁面或內容庫確認同一支影片是否已發布；若使用者要求更新既有貼文，優先編輯原貼文，避免重複發布。

## 發布

1. 依影片和使用者要求選擇 Reel 或一般影片貼文。以選檔介面上傳實際 MP4；若瀏覽器工具支援 file chooser，先等待 `filechooser`，點上傳控制項，再以 `chooser.setFiles(...)` 指定絕對路徑，不要求使用者代選。
2. 填入當次確認的文案，檢查預覽、受眾、排程及平台要求的標示。不要沿用前一支影片的文案或權限；AI 內容標示依實際素材與平台要求判斷。
3. 等平台完成上傳與初步檢查，再依當次授權發布。發布中的提示不是完成證據；如平台仍在處理，繼續回查。

## 完成條件

- 在台南AI爽粉絲專頁找到新 Reel 或貼文，開啟專屬連結，核對頁面身分、文案及實際分享對象。若平台仍在處理，明確回報處理狀態，不宣稱已可觀看。
- 回報已核對的 Facebook 連結與權限；只記錄實際觀察到的字幕、封面及播放狀態。
