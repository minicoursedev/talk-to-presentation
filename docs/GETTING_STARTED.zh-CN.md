# 第一次使用「说说变简报」

这份指南列出第一次使用与每次制作需要决定的事情。可以直接复制下面的范本开始；尚未决定的栏位填「请协助整理」，不必等全部有答案才开始。

默认核心模板为“说书人”：以整份简报的故事线统整逐页画面、旁白与节奏。用户可修改或替换模板；新案件保存所选版本的快照，既有案件不随共用模板变动。

## 1. Clone 后：先检查环境

将下载的专案放在自己选择的目录，目录名称不限。以包含工作区指引的目录开启任务；如果只取得制作能力包，也可直接开启该包。能力根目录是包含 `tools/`、`model.json` 及 `.agents/skills/presentation-production/` 的位置，不需要使用别人的本机路径。

可以先对助手说：

> 请依专案说明检查并建立制作环境，沿用符合需求的既有工具，完成后列出已通过的检查与仍缺少的输入。

助手应自行查证系统、实际路径、已安装工具与依赖是否符合要求。你不需要回答能由本机检查得到的资讯；建议版本不等于唯一可用版本。现行能力包的安装目标与限制见 [环境建立](SETUP.zh-CN.md)。安装依赖需要网路，模型权重及参考录音是配音前另外需要准备的项目。

## 2. 开始内容：先回答三件事

| 问题 | 可以怎么回答 | 还没确定时 |
| --- | --- | --- |
| 想说什么？ | 想法、问题、文件、网址，或既有简报；若只处理其中一部分，指出范围 | 先说目前想到的内容，请助手整理主题 |
| 说给谁听，希望对方理解什么？ | 受众的背景，以及希望他们理解、记住或采取的行动 | 请助手协助厘清受众与目的 |
| 用在哪里？ | 现场演讲、自行阅读、课程或社群影片；有时间、页数、画幅限制就补充 | 先描述使用情境，由助手提出合适选项 |

若已有文件，助手应先读取再整理，不要求你重填文件已交代的资讯。

## 3. 制作前：选择这次的成果与呈现方式

| 选择 | 你需要决定的内容 | 未指定时的处理 |
| --- | --- | --- |
| 输出 | 高桥流文字 HTML、美化 HTML、含旁白 MP4，或全部；先做草稿还是完成制作 | 先整理内容与提出输出建议，不假设已授权所有生成工作 |
| 视觉风格 | 看过 [风格参考](../shared/styles/default/style.zh-CN.md) 后沿用、调整，或提供自己的参考 | 助手主动展示现有参考，说明预设与可调整处 |
| 图片安排 | 是否每页都要图片，以及有没有指定图片或图表 | 制图前提出符合内容的逐页安排，厘清影响交付的选择 |
| 品牌 | 名称、Logo；也可以选择中性呈现 | 主动说明目前使用示范品牌，不把它当成正式品牌 |
| 配音与语速 | 需要配音时选择声线、语气与播放速度 | 先检查已有的声音资源；只询问尚缺的选择，不沿用其他案件的个别设定 |

上述选择可在对话中逐步确定。已提供过的需求不重问；已明确要求完成的制作继续执行，不因本表再增加确认关卡。

## 4. 只有需要配音时，才准备参考录音

参考录音放在 `$PRESENTATION_DATA_ROOT/shared/voice/reference-voice/`，在同目录的 `README.md` 记录语气、档名与实际逐字稿。`init_data.py` 会从[语气清单模板](../templates/voice-catalog.zh-CN.md)建立这份档案；编辑资料目录中的副本，保留仓库模板。工具只读取 `README.md`，即使阅读其他语言文件也相同。只需提供会用到的语气；已有对应资料时直接沿用。

助手应在开始配音前检查录音及模型，及早列出缺项。需要转换格式时保留原档。详细格式与操作见 [配音流程](../.agents/skills/presentation-production/references/voice.zh-CN.md)。若尚缺录音，仍可先整理内容与完成已授权、不受影响的部分。

```text
使用场合：
时间、页数或画幅限制（没有可写「无」）：

这次先整理与预览，或直接完成哪些制作：

```

## 接下来你会看到什么

助手先整理内容理解、目前选择与重要缺项，再提供逐页草稿及风格预览，依已授权的范围制作。你可以用页码或内容指出修订，无须重说整份需求。

开始制作后，助手将决策、参考路径、授权与进度记在案件 `content/draft.md`。交付时分别回报产物、已完成的技术检查与实际视听验收；尚缺的部分要明示。后续案件可以指定沿用哪些偏好，助手应说明沿用范围。
