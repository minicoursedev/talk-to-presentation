# 第一次使用「說說變簡報」

這份指南列出第一次使用與每次製作需要決定的事情。可以直接複製下面的範本開始；尚未決定的欄位填「請協助整理」，不必等全部有答案才開始。

預設核心樣板為「說書人」：以整份簡報的故事線統整逐頁畫面、旁白與節奏。使用者可修改或替換樣板；新案件保存所選版本的快照，既有案件不隨共用樣板變動。

## 1. Clone 後：先檢查環境

將下載的專案放在自己選擇的目錄，目錄名稱不限。以包含工作區指引的目錄開啟任務；如果只取得製作能力包，也可直接開啟該包。能力根目錄是包含 `tools/`、`brand.json` 及 `.agents/skills/presentation-production/` 的位置，不需要使用別人的本機路徑。

可以先對助手說：

> 請依專案說明檢查並建立製作環境，沿用符合需求的既有工具，完成後列出已通過的檢查與仍缺少的輸入。

助手應自行查證系統、實際路徑、已安裝工具與依賴是否符合要求。你不需要回答能由本機檢查得到的資訊；建議版本不等於唯一可用版本。現行能力包的安裝目標與限制見 [環境建立](SETUP.md)。安裝依賴需要網路，模型權重及參考錄音是配音前另外需要準備的項目。

## 2. 開始內容：先回答三件事

| 問題 | 可以怎麼回答 | 還沒確定時 |
| --- | --- | --- |
| 想說什麼？ | 想法、問題、文件、網址，或既有簡報；若只處理其中一部分，指出範圍 | 先說目前想到的內容，請助手整理主題 |
| 說給誰聽，希望對方理解什麼？ | 受眾的背景，以及希望他們理解、記住或採取的行動 | 請助手協助釐清受眾與目的 |
| 用在哪裡？ | 現場演講、自行閱讀、課程或社群影片；有時間、頁數、畫幅限制就補充 | 先描述使用情境，由助手提出合適選項 |

若已有文件，助手應先讀取再整理，不要求你重填文件已交代的資訊。

## 3. 製作前：選擇這次的成果與呈現方式

| 選擇 | 你需要決定的內容 | 未指定時的處理 |
| --- | --- | --- |
| 輸出 | 高橋流文字 HTML、美化 HTML、含旁白 MP4，或全部；先做草稿還是完成製作 | 先整理內容與提出輸出建議，不假設已授權所有生成工作 |
| 視覺風格 | 看過 [風格參考](../shared/styles/default/style.md) 後沿用、調整，或提供自己的參考 | 助手主動展示現有參考，說明預設與可調整處 |
| 圖片安排 | 是否每頁都要圖片，以及有沒有指定圖片或圖表 | 製圖前提出符合內容的逐頁安排，釐清影響交付的選擇 |
| 品牌 | 名稱、Logo；也可以選擇中性呈現 | 主動說明目前使用示範品牌，不把它當成正式品牌 |
| 配音與語速 | 需要配音時選擇聲線、語氣與播放速度 | 先檢查已有的聲音資源；只詢問尚缺的選擇，不沿用其他案件的個別設定 |

上述選擇可在對話中逐步確定。已提供過的需求不重問；已明確要求完成的製作繼續執行，不因本表再增加確認關卡。

## 4. 只有需要配音時，才準備參考錄音

參考錄音放在使用者資料根目錄下的 `shared/voice/reference-voice/`，並在 [語氣清單](../templates/voice-catalog.md) 記錄語氣、檔名與實際逐字稿。只需提供會用到的語氣；已有對應資料時直接沿用。

助手應在開始配音前檢查錄音及模型，及早列出缺項。需要轉換格式時保留原檔。詳細格式與操作見 [配音流程](../.agents/skills/presentation-production/references/voice.md)。若尚缺錄音，仍可先整理內容與完成已授權、不受影響的部分。

## 可直接複製的開始範本

```text
我要用「說說變簡報」製作一份簡報。

主題／想法／來源：
來源使用範圍（若適用）：
受眾與希望傳達的重點：
使用場合：
時間、頁數或畫幅限制（沒有可寫「無」）：

這次要的輸出（也可寫「請建議」）：
視覺風格（沿用參考／提供參考／請協助選擇）：
圖片安排（每頁有圖／請提出安排／其他）：
品牌（名稱與 Logo／中性呈現／稍後決定）：
配音（需要／不需要／稍後決定）：
已有的參考錄音與語氣資料（若適用）：
語速（若適用；未決定可請建議）：

這次先整理與預覽，或直接完成哪些製作：
尚未決定的部分，請依現有資訊協助整理。
```

## 接下來你會看到什麼

助手先整理內容理解、目前選擇與重要缺項，再提供逐頁草稿及風格預覽，依已授權的範圍製作。你可以用頁碼或內容指出修訂，無須重說整份需求。

開始製作後，助手將決策、參考路徑、授權與進度記在案件 `content/draft.md`。交付時分別回報產物、已完成的技術檢查與實際視聽驗收；尚缺的部分要明示。後續案件可以指定沿用哪些偏好，助手應說明沿用範圍。
